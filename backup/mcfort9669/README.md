# PS4 WEBKIT · MCFORT9669

**Веб-хост для PlayStation 4** с выбором подходящего модуля по версии прошивки. Проект объединяет собственный интерфейс MCFORT9669 и открытые разработки сообщества PS4.

**Открыть хост:** https://ps4webkit.github.io/9669/  
**Текущая версия пакета:** v11.2

> Версия на GitHub Pages обновится после загрузки файлов v11.2 в репозиторий. Проверить фактически установленную версию можно в разделе «Информация» самого хоста.

## Что умеет хост

- Определяет прошивку PS4 по данным браузера и выбирает маршрут из точного списка поддерживаемых версий.
- Показывает обнаруженную прошивку, выбранный модуль и соответствующую ему версию GoldHEN; по нажатию на надпись GoldHEN открывает пояснение.
- Предлагает большую кнопку запуска, отображает этапы, журнал и состояние подготовки файлов.
- Сохраняет настройки оформления; по умолчанию включена тёмная тема. Есть переключатель автоматического запуска.
- Показывает статистику для запусков, результат которых может подтвердить главная страница. Запуски отдельных модулей не входят в общую статистику автоматически.
- Готовит локальные файлы для офлайн-работы через кэш браузера PS4. У подключённых модулей могут быть собственные отдельные кэши.
- При обнаруженной ошибке показывает прошивку, модуль и этап, чтобы было удобнее отправить скриншот. После внезапного закрытия браузера хост может показать сохранённый последний этап; это подсказка для диагностики, а не журнал сбоя ядра.

## Как пользоваться

1. Откройте адрес хоста в браузере PS4 и дождитесь подготовки файлов.
2. Убедитесь, что определилась ваша прошивка. Если её нет в таблице, запуск не предлагается.
3. Нажмите «ВЗЛОМ» и следуйте подсказкам выбранного модуля. Для некоторых версий откроется его отдельная страница.
4. Если появилась ошибка, сделайте скриншот окна с прошивкой и этапом и приложите его к сообщению о проблеме.

После публикации обновления GitHub Pages и браузеру PS4 может понадобиться время, чтобы получить новый файл кэша. Если видите старую версию, подождите около 10 минут, полностью закройте браузер и откройте хост заново. Версию смотрите в «Информация».

## История проекта

| Версии | Что менялось |
| --- | --- |
| **v1–v10 · ранний этап** | Появился первоначальный хост для PS4, затем развивались интерфейс запуска, отображение состояния и статистики, журнал, руководство, настройки оформления, оформление кнопки и работа с офлайн-кэшем. Подробный список изменений каждого раннего номера не сохранился в доступной истории репозитория; этот блок описывает развитие проекта в целом. |
